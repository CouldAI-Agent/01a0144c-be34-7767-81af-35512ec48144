# RSA Cryptography Educational App

An interactive presentation app that visually walks through the concepts of RSA Cryptography, built entirely in Flutter.

## Features
- **Presentation Flow**: Six well-structured educational slides covering RSA cryptography.
- **Mathematical Transparency**: Detailed, step-by-step breakdowns of key mathematical concepts such as prime selection, Euler's totient function, key generation, and modulo operations.
- **Responsive Layout**: Designed to adapt and scale beautifully on mobile, web, and desktop.
- **Interactive Navigation**: Easy page-based navigation with progress tracking and smooth transitions.

## Content Covered
1. **Welcome to RSA Cryptography**: History and core dual-key concepts.
2. **Mathematical Infrastructure**: Selecting primes and calculating base modulus and Euler's Totient helper number.
3. **Asymmetric Key Generation**: Selecting public encryption keys and calculating private decryption keys.
4. **Key Verification Check**: Utilizing the Absolute Remainder Rule to verify mathematical accuracy.
5. **Plaintext Conversion & Encryption**: Locking data with ASCII conversion and modulo math.
6. **Decryption Flow & Retrieval**: Unlocking intercepted numerical sequences back to plain text.

## Tech Stack
- Framework: Flutter
- State Management: Stateful Widgets and PageControllers
- Navigation: Standard Flutter Routing

## Setup and Run
1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. Clone this repository and navigate to the directory.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the presentation on your connected device or web browser.
